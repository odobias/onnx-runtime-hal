# models.speech.whisper-multilingual-accuracy-samples

Six short FLEURS clips covering German, French, Spanish, Czech, Italian, and
Polish. They exercise automatic language detection and verbatim transcription
with the multilingual Whisper model across CPU, GPU, and vendor NPU executors.

`samples.json` commits each language, transcription reference, parallel English
reference, source identity, and CPU full-window WER baseline. Some languages are
intentionally difficult for Whisper Tiny; the baselines are regression limits,
not a claim that Tiny has production-grade multilingual accuracy.

WAV binaries remain in the private `gendigital/npu-hal-over-9000` Hugging Face
repository. `models.json` pins an immutable HF revision and `SHA256SUMS`
verifies every download. The package build needs `HF_TOKEN`; consumers obtain
the resulting NuGet anonymously from Artifactory.

Published as `models.speech.whisper-multilingual-accuracy-samples` to
nuget-local by the autogenerated TeamCity job after a push to the version
branch.

# models.speech.fakeaudio-samples

Balanced FakeAudio correctness corpus for executor and vendor regression tests:
five real and five synthetic clips from the model team's own ONNX export-smoke
kit. The model classifies all ten with a wide margin, making decision flips or
large probability drift useful signals across CPU, GPU, and NPU providers.

`samples.json` commits the labels, CPU reference probabilities, model hash, and
gate tolerances. WAV binaries stay in the private
`gendigital/npu-hal-over-9000` Hugging Face repository. `models.json` pins an
immutable HF revision and `SHA256SUMS` verifies every download. The package build
therefore needs `HF_TOKEN`; consumers obtain the resulting NuGet anonymously
from Artifactory.

This deliberately excludes the five legacy YouTube efficacy-review clips. They
were sampled only from production-flagged cases and are biased toward the old
classifier's boundary, so they are inferior unit-test fixtures.

Published as `models.speech.fakeaudio-samples` to nuget-local by the autogenerated
TeamCity job after a push to the version branch.

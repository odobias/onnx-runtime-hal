#   x64  + Intel NPU/GPU (OVEP)   pip install onnxruntime-openvino   (or onnxruntime-ep-openvino)
#   x64  + AMD NPU (VitisAI)      use the Ryzen AI SDK conda env (its OWN custom onnxruntime; do not pip-install another)
#   ARM64 CPU + Qualcomm NPU      pip install onnxruntime-qnn        (ARM64 Python; x64 QNN wheel is AOT-compile-only)
#
# Everything below is platform-agnostic and safe to pin.
